# EcoDash-African-Logistics
EcoDash is an interactive 2D web app designed to replicate real-world logistics and supply chain challenges of delivering essential goods across rural and neglected areas in African regions.

This project features a web-based logistics simulation in which the player manages a delivery vehicle while navigating various environmental and operational factors. It has been built using HTML5 Canvas, JavaScript, and CSS.

The project context focuses on logistics disruptions in South Africa, highlighting load-shedding as a supplier-related operational issue that can affect production and distribution.

Setup Instructions

Running it in your browser
1. Download and extract the project
2. Open the project folder
3. Open the index.html file in a browser of your choice
4. Click Start Mission
5. Controls are listed underneath the game 

Run with Visual Studio Code
1. Open the project folder in Visual Studio Code
2. Install the Live Server extension if necessary
3. Open the index.html file
4. Right-click the file and select Open with Live Server
5. The project opens in the browser

Controls

W / Up Arrow        Accelerate
S / Down Arrow      Reverse
A / Left Arrow       Steer Left
D / Right Arrow     Steer Right
H        Horn
P       Pause / Resume
R       Restart
